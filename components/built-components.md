- **No icon system** — every icon is a loose file in `public/icons/` (UI) or `public/SVG/` (illustration assets), no registry/manifest, no shared `Icon` component. Two ad-hoc conventions in use depending on need: `<img src="/icons/x.svg">` for static icons, or the raw `<svg>` markup inlined directly in JSX when `currentColor` needs to resolve from context (button badges, `GhostCursor`, `WorkCaseStudyRow`'s arrow-outward icon). Flagged while building the live-embed banner's expand/collapse icons — not addressed there, just noted.
